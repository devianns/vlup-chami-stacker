# 차미 우겨넣기 게임 규칙

## 목표

빨간 한계선을 넘지 않도록 상자 안의 빈틈에 차미를 최대한 많이 넣습니다. 안정된 차미의 윗부분이 한계선을 1.1초 이상 넘으면 게임이 끝납니다. 선을 넘기게 만든 마지막 차미는 점수에 포함되지 않습니다. 목숨, 시간제한, 낙하 횟수 제한은 없습니다.

## 공정한 차미 순서

모든 플레이는 `stacking.sequence`에 선언된 같은 순서를 사용합니다. 배열의 끝에 도달하면 처음부터 반복합니다. 시작할 때 정해지는 무작위 모양이나 기기별 난이도 차이는 없습니다. 차미의 초기 기울기도 놓은 순서로 결정됩니다.

## 점수

```text
총점 = 차미 개수 × 10,000 + 빈틈 보너스
빈틈 보너스 = 각 차미의 배치 밀집도 평균을 0~9,999점으로 환산
```

차미 하나의 점수는 빈틈 보너스의 최댓값보다 큽니다. 따라서 차미 6개를 넣은 기록은 밀집도와 관계없이 차미 5개 기록보다 항상 높습니다. 차미 개수가 같을 때만 더 낮고 촘촘하게 배치한 기록이 앞섭니다.

개수 점수와 빈틈 보너스는 정수만 사용하며, 최종 점수 저장 전에 같은 공식으로 다시 검증합니다.

## 순위 비교

1. 넣은 차미 개수
2. 평균 밀집도
3. 최종 점수
4. 먼저 달성한 기록

현재 순위표는 브라우저의 로컬 저장소를 사용합니다. 온라인 순위표를 붙일 때에는 콘텐츠 버전, 동일 차미 순서, 입력 기록을 서버에서 다시 검증해야 합니다.
