# 차미 우겨넣기 게임 규칙

## 목표

빨간 한계선을 넘지 않도록 상자 안의 빈틈에 차미를 최대한 많이 넣습니다. 안정된 차미의 윗부분이 한계선을 1.1초 이상 넘으면 게임이 끝납니다. 선을 넘기게 만든 마지막 차미는 점수에 포함되지 않습니다. 목숨, 시간제한, 낙하 횟수 제한은 없습니다.

## 랜덤 차미 규칙

차미는 작은·중간·큰 크기와 기본·납작·길쭉·삐딱 모양을 조합한 12종으로 나옵니다. 완전 독립 추첨 대신 12종이 한 번씩 들어 있는 `stacking.bag`을 섞어 꺼내는 셔플 백 방식을 사용하고, 한 주머니를 모두 사용하면 다시 섞습니다. 한 주머니 단위의 구성은 모두에게 같고 등장 순서만 무작위이므로 특정 크기만 계속 나오는 편향을 줄입니다.

게임 시작 시 생성한 `runSeed`로 차미 순서와 초기 기울기를 결정합니다. 같은 시드를 다시 계산하면 같은 추첨 결과를 재현할 수 있어 향후 온라인 점수 검증에도 사용할 수 있습니다.

## 점수

```text
크기 점수 = 작은 차미 6,000점 / 중간 차미 10,000점 / 큰 차미 15,000점
총점 = 쌓은 차미의 크기 점수 합계 + 밀집도 보너스
밀집도 보너스 = 각 차미의 배치 밀집도 평균을 0~2,999점으로 환산
```

게임이 끝나는 순간 빨간 선 아래에 남아 있는 차미를 크기별로 다시 세어 기본 점수를 확정합니다. 가장 작은 차미의 6,000점도 밀집도 보너스 최댓값 2,999점보다 크므로, 차미를 하나 더 안정적으로 넣어 얻은 점수가 밀집도 보너스 하나만으로 무효화되지는 않습니다. 큰 차미는 공간을 더 많이 차지하고 다루기 어려운 만큼 더 높은 고정 점수를 줍니다.

콘텐츠 v2.1부터 한계선은 렌더러 좌표 `Y=210`에 놓입니다. 이전 v2.0의 `Y=255`보다 위쪽으로 45px 이동해 유효 적재 높이가 655px에서 700px로 늘어났습니다. 밀집도는 `한계선~바닥` 전체 높이에 대한 각 차미 위치의 상대값으로 계산하므로, 넓어진 공간에서도 0~100%의 동일한 기준으로 비교됩니다. 규칙이 달라진 v2.0 기록은 v2.1 순위표와 섞지 않습니다.

콘텐츠 v2.2에서는 찌그러진 차미의 판정을 이미지 전체를 감싼 직사각형에서 흰색 몸통에 맞춘 사다리꼴로 변경했습니다. 잎과 몸 사이의 투명 영역은 더 이상 바닥이나 다른 차미와 충돌하지 않으며, 렌더 원점과 무게중심도 몸통 쪽으로 맞췄습니다. 물리 조건이 바뀌었으므로 v2.1 이전 기록은 v2.2 순위표와 분리합니다.

콘텐츠 v3.0에서는 한계선을 `Y=190`으로 20px 더 올리고, 세 가지 크기와 크기별 고정 점수를 도입했습니다. 차미의 마찰과 공기 저항을 낮추고 낙하 시 시드 기반의 작은 수평 속도와 회전을 부여해 더 잘 구르고 미끄러집니다. 서버는 제출된 크기별 개수로 기본 점수를 다시 계산하며 v2 기록과 순위표를 분리합니다.

콘텐츠 v3.0.1에서는 삐딱 차미의 사다리꼴 판정과 별도 원점·무게중심 보정을 제거했습니다. 세 크기 모두 같은 정규화 몸통 외곽 다각형을 확대해 사용하므로 이미지 한쪽으로 판정이 치우치지 않으며, 잎과 손발의 투명 여백은 충돌하지 않습니다.

크기별 개수, 크기 점수와 밀집도 보너스는 정수만 사용합니다. 최종 점수 저장 전 클라이언트와 서버가 크기별 개수 합계, 기본 점수와 최종 점수를 같은 공식으로 다시 검증합니다.

## 순위 비교

1. 최종 총점
2. 평균 밀집도
3. 넣은 차미 개수
4. 먼저 달성한 기록

전체 순위표는 Vercel 서버리스 API와 Neon 데이터베이스를 사용합니다. 브라우저 로컬 저장소는 통신에 실패했을 때 기록을 잃지 않기 위한 보조 저장소입니다. 서버에는 콘텐츠 버전과 `runSeed`도 함께 저장됩니다.
