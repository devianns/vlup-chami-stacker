# 차미 우겨넣기 게임 규칙

## 목표

빨간 한계선을 넘지 않도록 상자 안의 빈틈에 차미를 최대한 많이 넣습니다. 안정된 차미의 윗부분이 한계선을 1.1초 이상 넘으면 게임이 끝납니다. 선을 넘기게 만든 마지막 차미는 점수에 포함되지 않습니다. 목숨, 시간제한, 낙하 횟수 제한은 없습니다.

## 랜덤 차미 규칙

차미는 매 게임 무작위 순서로 나옵니다. 다만 완전 독립 추첨 대신 `stacking.bag`에 들어 있는 차미를 한 번씩 섞어 꺼내는 셔플 백 방식을 사용합니다. 한 주머니를 모두 사용하면 다시 섞습니다. 덕분에 다음 차미를 예측하는 재미는 유지하면서 특정 모양만 지나치게 연속해서 나오는 상황은 줄어듭니다.

게임 시작 시 생성한 `runSeed`로 차미 순서와 초기 기울기를 결정합니다. 같은 시드를 다시 계산하면 같은 추첨 결과를 재현할 수 있어 향후 온라인 점수 검증에도 사용할 수 있습니다.

## 점수

```text
총점 = 차미 개수 × 10,000 + 빈틈 보너스
빈틈 보너스 = 각 차미의 배치 밀집도 평균을 0~9,999점으로 환산
```

게임이 끝나는 순간 빨간 선 아래에 남아 있는 차미를 다시 세어 최종 개수를 확정합니다. 차미 하나의 점수는 빈틈 보너스의 최댓값보다 큽니다. 따라서 차미 6개를 넣은 기록은 밀집도와 관계없이 차미 5개 기록보다 항상 높습니다. 차미 개수가 같을 때만 더 낮고 촘촘하게 배치한 기록이 앞섭니다.

개수 점수와 빈틈 보너스는 정수만 사용하며, 최종 점수 저장 전에 같은 공식으로 다시 검증합니다.

## 순위 비교

1. 넣은 차미 개수
2. 평균 밀집도
3. 최종 점수
4. 먼저 달성한 기록

전체 순위표는 Vercel 서버리스 API와 Neon 데이터베이스를 사용합니다. 브라우저 로컬 저장소는 통신에 실패했을 때 기록을 잃지 않기 위한 보조 저장소입니다. 서버에는 콘텐츠 버전과 `runSeed`도 함께 저장됩니다.
